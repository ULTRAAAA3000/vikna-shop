# Vikna Shop

Концепт-лендінг металопластикових вікон і дверей з 3D-конструктором і формою заявки.

**Стек:** TypeScript · Vite · three.js · Cloudflare Workers (статика + API) · Cloudflare D1.

## Що всередині

| Розділ | Опис |
| --- | --- |
| Hero | Анімована стулка, що розчиняється при прокручуванні |
| Про нас | Історія, цінності, переваги |
| Продукція | Вікна, балконні двері, вхідні двері, розсувні системи — кнопка «Налаштувати» відкриває виріб у конструкторі |
| Розробка | Як ми проєктуємо під отвір: замір → проєкт → виробництво → монтаж |
| 3D-конструктор | Розмір, конструкція, форма (прямокутник / арка), профіль, колір (у т. ч. дерево), скло, заповнення дверей, відкривання стулок, розрахунок ціни |
| Прайс-лист | Вкладки за категоріями, ціни генеруються з того самого каталогу, що й конструктор |
| Заявка | Контакти + запит клієнта; конфігурація з конструктора додається до заявки |

## Структура

```
index.html            розмітка сторінки
src/                  фронтенд (TypeScript)
  main.ts             точка входу
  ui.ts               шапка, анімації появи, hero, лічильники
  products.ts         картки продукції
  prices.ts           прайс-лист
  order-form.ts       форма заявки
  store.ts            зв'язок між блоками (картки → конструктор → форма)
  configurator/
    panel.ts          UI і стан конструктора
    scene.ts          3D-сцена (three.js), вантажиться окремим чанком
shared/               код, спільний для фронтенду й воркера
  catalog.ts          каталог, опції, розрахунок ціни, прайс
  order.ts            валідація заявки
worker/index.ts       Cloudflare Worker: POST/GET /api/orders
schema.sql            єдина схема D1
wrangler.toml         конфігурація Cloudflare
```

Ціну із заявки воркер **перераховує сам** з каталогу, значенню з браузера не довіряє.
Конфігурація з браузера також проходить санітизацію (допустимі значення, межі розмірів).

## Локальний запуск

```bash
npm install
npm run db:local     # створює локальну D1 зі schema.sql
npm start            # збірка + wrangler dev → http://localhost:8787
```

Для розробки фронтенду з гарячим перезавантаженням у двох терміналах:

```bash
npm run dev:api      # воркер + D1 на :8787
npm run dev          # Vite на :5173, /api проксюється на воркер
```

Перегляд заявок локально: скопіюйте `.dev.vars.example` у `.dev.vars` і виконайте

```bash
curl http://localhost:8787/api/orders -H "authorization: Bearer <ADMIN_TOKEN>"
```

## Деплой у Cloudflare

```bash
npx wrangler login
npx wrangler d1 create vikna-shop          # скопіюйте database_id у wrangler.toml
npm run db:remote                          # застосувати schema.sql
npx wrangler secret put ADMIN_TOKEN        # токен для GET /api/orders
npm run deploy
```

## API

- `POST /api/orders` — створити заявку (JSON). Відповіді: `201 {ok,id,estimate}`, `422 {errors}`, `429` (ліміт 3 заявки/10 хв з одного номера).
- `GET /api/orders` — список останніх 200 заявок, потрібен `Authorization: Bearer <ADMIN_TOKEN>`.
- `GET /api/health` — перевірка живості.

## Що замінити перед запуском у роботу

Тексти, контакти (`index.html`), ціни й опції (`shared/catalog.ts`) — демонстраційні.
Реальні фото виробництва й об'єктів у макеті не використовуються; їх можна додати в `public/` і підключити в розділи «Про нас» та «Продукція».
